# Rio Año Nuevo 2027 · Itinerario

Página estática lista para Vercel sobre el viaje de 4 amigos a Rio de Janeiro del **27 de diciembre de 2026 al 2 de enero de 2027**.

Incluye:

- Itinerario día por día
- Hoteles reales/referencias actuales
- Vuelos Miami–Rio y rangos históricos
- Opciones de fiesta NYE en Copacabana
- Presupuesto por escenarios
- Próximos pasos de reserva
